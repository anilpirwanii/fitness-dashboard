# Fitness Dashboard

A fully dynamic fitness and macro tracking dashboard built with TanStack Start.

## Features
- **Barcode Scanning**: Real-time product lookup via Open Food Facts API.
- **Meal Grouping**: Organized views for Breakfast, Lunch, Dinner, and Snacks.
- **Macro Tracking**: Visual progress rings for Calories, Protein, Carbs, and Fat.
- **Safety First**: Confirmation prompts for all meal deletions.
- **Responsive Design**: Modern, clean UI with full dark/light mode support.

## Tech Stack
- [TanStack Start](https://tanstack.com/start)
- React + Vite
- Tailwind CSS
- Lucide React Icons
- Open Food Facts API
